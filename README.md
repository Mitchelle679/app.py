# app.py
We define our Task Object as task_id, task_title, is_completed. Method, Endpoint, Description, Get- /tasks, Retrieve all tasks. Post- /tasks, create a new task. Put- /tasks/&amp;lt;id> Mark task as completed. Delete- /tasks/&lt;id> Remove a task. We will perform unit testing to ensure that the task_title cannot be empty and that the is_completed status.
